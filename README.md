# Expense Tracker App

A simple desktop application built with VB.NET (Windows Forms) to track daily expenses.

## 🚀 Features
- Add expenses with category
- View list of expenses
- Automatic total calculation
- Input validation

## 🛠️ Technologies Used
- VB.NET
- Windows Forms

## 📸 Future Improvements
- Save data to file or database
- Filter by category
- Better UI design

This project was built as part of my journey to becoming a software developer.
